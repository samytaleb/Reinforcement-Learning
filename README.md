# Reinforcement Learning — Algorithms and Notebooks

A collection of educational **reinforcement learning** notebooks, covering model-based methods, model-free learning, and deep reinforcement learning.

## Notebooks

| Topic | Notebook |
| --- | --- |
| Dynamic programming | [DYN_PROG.ipynb](DYN_PROG.ipynb) |
| Monte Carlo methods | [MONTE_CARLO.ipynb](MONTE_CARLO.ipynb) |
| Temporal-difference learning | [Temporal_Difference.ipynb](Temporal_Difference.ipynb) |
| Q-learning | [Q_LEARNING.ipynb](Q_LEARNING.ipynb) |
| Deep Q-Networks | [Deep_Q_Network.ipynb](Deep_Q_Network.ipynb) |
| Policy gradients (REINFORCE) | [REINFORCE.ipynb](REINFORCE.ipynb) |

## Getting started

Open the notebooks using JupyterLab or VS Code. Install the packages imported in each notebook and execute its cells in order. Depending on the exercises, additional environment or ML framework dependencies may be required.

## Suggested learning path

Begin with dynamic programming, then Monte Carlo and temporal-difference methods, followed by Q-learning, Deep Q-Networks, and REINFORCE.

These notebooks are educational implementations; they are not presented as a production-ready RL framework.
